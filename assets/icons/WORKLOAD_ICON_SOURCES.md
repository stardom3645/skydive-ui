- `daemonset-controller.svg`: optimized from the Kubernetes Community resource icon set `ds.svg`, Apache-2.0 or CC-BY-4.0.
  - https://github.com/kubernetes/community/blob/main/icons/svg/resources/unlabeled/ds.svg

  - https://github.com/kubernetes/community/blob/main/icons/svg/resources/unlabeled/svc.svg

Deployment and DaemonSet follow the Kubernetes resource visual language and use Netdive's contextual icon colors.
